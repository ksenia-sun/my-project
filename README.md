# 🐍 "Змейка" (Snake Game)

Это реализация классической игры "Змейка", написанная на чистом JavaScript (ES6+), HTML и CSS. Проект создан с упором на современный код, ООП, адаптивность и внимание к техническим деталям.

## 🚀 Запуск проекта

Проект не требует сборки или зависимостей.  
Ссылка: https://ksenia-sun.github.io/my-project/snake/  
Или клонируйте репозиторий и откройте файл `index.html` в любом браузере.

## 🎮 Реализованный функционал

* **Полный игровой цикл:** старт, игра, пауза, конец игры.
* **Адаптивный дизайн:** корректно отображается и играется на десктопах, планшетах и смартфонах.
* **Сохранение рекорда:** лучший счет сохраняется в `localStorage` между игровыми сессиями.
* **Динамическое ускорение:** скорость игры плавно возрастает по мере набора очков.
* **Пошаговые инструкции:** перед началом игры отображается простой двушаг.
* **Гибкое управление:** поддержка клавиатуры (стрелки + пробел) и сенсорного ввода (свайпы + тап).
* **Опция "Подсветка пути":** дополнительная функция (включается чекбоксом) для подсветки текущей горизонтали и вертикали змейки.
* **Отклик на действие:** вибрация на телефонах при поедании яблока.

## 🌟 Ключевые технические особенности

### 1. Архитектура и игровой цикл

* **Объектно-ориентированный подход:** вся игровая логика инкапсулирована в класс `SnakeGame`.
* **Игровой цикл на `requestAnimationFrame`:** вместо `setInterval`, который может быть неточным, используется `requestAnimationFrame` (rAF) для отрисовки.
* **Стабильная скорость (Time-based logic):** скорость игры *не зависит* от частоты обновления монитора (FPS). Логика обновления (`updateGame`) вызывается только тогда, когда накопленная разница во времени (`deltaTime`) превышает заданную скорость (`gameSpeed`). Это обеспечивает предсказуемый и стабильный геймплей на любых устройствах.
* **Развитый UI и state-machine:** управление игрой реализовано через четкую систему состояний: `START`, `PLAYING`, `PAUSE`, `GAMEOVER`. Это позволяет декларативно управлять UI (через `data-state` в CSS) и логикой.
* **Надежный алгоритм генерации еды:** eда генерируется с использованием цикла do/while, который гарантирует, что новая клетка для еды всегда будет выбрана исключительно из свободных ячеек поля, не пересекаясь с телом змейки.

### 2. Адаптивность

* **Data-driven design:** параметры игры (размер сетки, скорость, шаги ускорения) не "захардкодены", а меняются в зависимости от ширины экрана. Это реализовано через массив `responseBreakpoints` в настройках.
* **Оптимизация `resize`:** для событий `resize` и `orientationchange` используется `debounce`, чтобы предотвратить избыточные вычисления при изменении размера окна.
* **Динамический сanvas:** размер `<canvas>` всегда остается квадратным и кратным размеру сетки (`gridSize`), что исключает появление "дробных" пикселей или неполных ячеек на поле.

### 3. Управление

* **Гибридная система ввода:** реализована полная поддержка как десктопных, так и мобильных устройств.
* **Защита от "разворота на 180°":** нажатия клавиш не меняют направление (`direction`) мгновенно, а записываются в буфер (`nextDirection`). Направление активируется только в момент выполнения очередного логического цикла движения змейки. Это гарантирует, что смена направления происходит синхронно с перемещением и предотвращает баг с разворотом на 180° - мгновенный разворот змейки в себя.
* **Различение "Тапа" и "Свайпа":** на мобильных устройствах реализована логика, которая четко разделяет:
    * **Tap:** быстрое касание для "Паузы" / "Возобновления".
    * **Swipe:** движение для управления направлением.
    Логика основана на времени касания (`MAX_TAP_DURATION_MS`) и пройденной дистанции (`minSwipeDistance`).

### 4. Разделение логики и стилизации

* **CSS custom properties:** все ключевые цвета игры (змея, еда, сетка) заданы в CSS как переменные (`--game-food`, `--game-snake-head` и т.д.).
* **Темизация через JS:** класс `SnakeGame` при инициализации считывает эти CSS-переменные (`readThemeFromCSS`). Это позволяет полностью менять внешний вид игры, **не внося изменений в JavaScript-код**.
* **Декларативное UI:** состояния UI (например, отображение "Game Over" или "Pause") управляются в CSS через `data-state` атрибут на главном контейнере, который устанавливает JS.
